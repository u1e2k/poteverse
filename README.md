# Poteverse (ポテバース)

ANBERNIC RG Rotate（Android 12 / 720×720 スクエア液晶）向け スタンドアロン相棒育成ギアゲーム

---

## 🎮 コンセプト

- **「Pote」＝ 相棒・ダチ**: プレイヤーと画面の中の「ポテ」はペットと飼い主ではなく、対等な相棒（Buddy）として生活・冒険・鍛錬を共にします。
- **初代デジモン実機リスペクト**:
  - モノクロLCD液晶（オリーブグリーン `#9ba78a` / ドットインク `#1e291e`）
  - 画面の端から端までてくてく歩き回る**広域パトロール歩行AI**
  - **世代ごとのドット絵サイズ差別化**: EGG/BABY（小） ──> CHILD（中） ──> ADULT（大） ──> MASTER（特大・迫力満点）
  - **🍖 食事メニュー**: 🍖 肉（満腹回復）と 💊 プロテイン（筋力/スタミナ）を選択
  - **💪 鍛錬メニュー**: 🏋️ 特訓（筋力UP）と ⚔️ 実戦バトル（簡易オートバトル・勝敗判定）
  - **進化ゲージ＆便意ゲージ非表示**: いつ進化するか分からないワクワク感と、突如やってくる「トイレ急げ！」のアラート演出
- **1セッション完結スケール**: 実時計（RTC）同期ではなく、プレイ中のTick進行により30分〜1時間で育成・進化・世代交代までがテンポよく完結。

## 🧬 種族・属性 & 4大進化ツリー

### 4種類のタマゴ選択
1. 🔥 **ドラタマ（竜卵）**: 熱血・格闘系
2. ⚡ **ビットタマ（電脳卵）**: 電脳・メカ系
3. 🐺 **ビスタマ（獣卵）**: 野性・ケモノ系
4. 👑 **ヌメタマ（変異卵）**: マイペース・変異系

### 自動分岐進化の判定ロジック
各成長段階（EGG: 50 Ticks / BABY: 60 Ticks / CHILD: 80 Ticks / ADULT: 120 Ticks）の目標Tickに達した時点で自動判定：
1. **実戦勝率 ＆ 対戦数** ──> 高勝率（70%以上）＋多数実戦で最強マスター形態へ！
2. **鍛錬不足 / 実戦経験不足** ──> 上位形態へなれず、進化保留（鍛錬継続）または変異種へ。
3. **お世話ミス多数 (3回以上)** ──> 👑 ヌメポテ系統 (MUTANT)

```text
[ EGG (4種) ] ─── ドラタマ / ビットタマ / ビスタマ / ヌメタマ
       │
[ BABY (4種) ] ── バブポテ / プチビット / パピポテ / プニポテ
       │
       ├─[ CHILD : BRAWLER ] ── ドラポテ  ──> [ ADULT ] バーンポテ ──> [ MASTER ] 覇神ウォーポテ
       ├─[ CHILD : TECH ]    ── ビットポテ ──> [ ADULT ] ギアポテ   ──> [ MASTER ] オメガビットポテ
       ├─[ CHILD : BEAST ]   ── ウルポテ   ──> [ ADULT ] ガルポテ   ──> [ MASTER ] 聖狼フェンリルポテ
       └─[ CHILD : MUTANT ]  ── ヌメポテ   ──> [ ADULT ] キングヌメ ──> [ MASTER ] コズミックポテ
```

## ⚙️ コアシステム & ハードウェア仕様

### 1. ターゲットプラットフォーム
- **ハードウェア**: ANBERNIC RG Rotate
- **OS**: Android 12
- **画面**: 720×720（1:1 スクエア液晶 / レトロLCDドットマトリクス演出）
- **入力**: 物理キー（十字キー, A/B/X/Y, L1/R1, L2/R2）、タッチスクリーン、6軸ジャイロ、開閉機構
- **エンジン**: Godot Engine 4.x (GDScript)

### 2. 時間進行 & 安全インターロック
- **通常Tick**: 1.0秒 = 1Tick でパラメータが進行。
- **R2 早送り（Fast-Forward）**: 物理キー `R2` を押下中、20倍速（0.05秒 = 1Tick）で高速時間進行（描画60fpsは等速維持）。
- **【最重要】オートストップ & 安全インターロック**:
  - 空腹限界・便意限界・過労・**進化/孵化到達**時に通常速度へ急停止。
  - Android端末振動（ハプティクス）によるキックバックと警告音を発火。
  - **R2を押しっぱなしにしていても早送りは再開せず、一度完全に指を離して押し直すまで早送りをブロック（安全インターロック）**。

### 3. ❄️ コールドスリープ保管庫（モンスターファーム風 凍結機能）
- **時間停止保存**: 凍結ポッド内の相棒は時間が完全に停止し、ステータス消費や寿命の減少が起こりません。
- **マルチスロット保存 (`user://cryo_storage.json`)**: 最大4スロットまで、育成履歴・総Tick・ステータス・戦績を永続化保存。
- **新タマゴ育成への引き継ぎ**: 育て上げた相棒をポッドに休ませたまま、4種類のタマゴから選んで新規育成が可能。
- **いつでも解凍復帰**: 過去に育てた相棒をいつでもワンボタンで液晶画面に呼び出して再開可能。
